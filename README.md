# local7 — Cleanza-inspired Sokxay desktop concept

A separate homepage concept inspired by https://cleanza.framer.website/: white sticky navigation, centered photo hero, rounded buttons, a three-column introduction band and a grid of image cards. Brand, descriptions, names and contact details use the Sokxay source site and existing analysis. The presentation uses selected sample content; complete content migration is deferred.

Run from this directory: `python3 -m http.server 49379 --bind 127.0.0.1`

The hero uses the original website’s illustrative photo. The former AI-generated city image remains in assets but is not displayed. Sector cards use illustrative Unsplash photos. Logo uses newly created sharp vector SVGs (`assets/sokxay-logo-landscape.svg` and `assets/sokxay-logo-vertical.svg`). Source website hosts management and news images; Google Fonts supplies fonts. Detail links lead to the original site. Desktop is the requested review target.

Sokxay-specific iteration uses the original logo colors and motif, and features selected organizations linked to their pages on the source website. Sector groupings are illustrative and await confirmation.
